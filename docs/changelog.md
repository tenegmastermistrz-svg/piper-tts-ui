## [Unreleased]

### Added
- Initial project setup.
- Core application `piperui.py` with PyQt5 interface.
- Support for Piper TTS, custom commands, ping, and echo modes.
- Text processing engine with customizable rules from JSON files.
- Hotkey support for speaking selected text, stopping processes, and quitting.
- System tray integration and desktop notifications.
- Persistent settings saved to a configuration file.
- Created documentation suite including:
    - `code_conventions.md`: Outlines the coding standards for the project.
    - `features.md`: Provides a detailed list of application features.
    - `readme.md`: A user-facing guide to the application.
    - `todo.md`: Lists ideas for future development.
    - `changelog.md`: This file, for tracking updates.
